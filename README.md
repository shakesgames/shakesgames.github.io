## Features

- No ads, no analytics, no accounts — just games
- Tab cloaking (disguise the tab as Google, Classroom, Canvas, and more)
- Panic button (quick-escape to a safe site) + `Ctrl+Shift+X`
- Open-in-about:blank mode

## Hosting

This is a static site — deploy it to GitHub Pages and it works. All game data
is served from this repository (and the shakesgames2-6 companion repos for
games on pages 2-6).

## Privacy

The site uses no ads, no analytics, and no third-party accounts. Cloak and
panic settings are stored locally in your browser only.
